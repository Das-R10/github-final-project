# Simple Interest Calculator

A lightweight Bash-based command-line tool that calculates simple interest based on user-provided inputs: principal amount, rate of interest, and time period.

## Project Overview

This project was created as part of the **Introduction to Git and GitHub** final assignment. It demonstrates core Git and GitHub workflows, including forking, cloning, branching, committing, merging, and creating pull requests, alongside standard open-source project documentation.

## Features

- Accepts principal amount, rate of interest, and time period as input
- Calculates simple interest using the formula: `SI = (P * R * T) / 100`
- Displays the result directly in the terminal

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Follow the on-screen prompts to enter the principal, rate of interest, and time period.
